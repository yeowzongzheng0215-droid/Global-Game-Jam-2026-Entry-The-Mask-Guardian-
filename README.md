## 🎨 My Role — Character Design & UI/UX Design

In a fast-paced 9-person jam environment, visual clarity and rapid asset turnaround are critical. My work bridged narrative aesthetics and player usability across two core areas:

### 1. User Interface (UI/UX) Design
* **Intuitive Game Flows:** Designed clean, readable screens covering the **Title Menu, Controls/Instructions, Pause Overlay, and End-of-Run Summary** so first-time players can jump in immediately.
* **In-Game HUD & Visual Feedback:** Crafted clear HUD indicators and status elements tailored to gameplay readability without obstructing the core play area.
* **Cohesive Visual Language:** Aligned typography, button states, framing, and color contrast with the atmospheric tone of *The Mask Guardian*.

### 2. Character Design & Visual Identity
* **Concept Ideation:** Developed character designs centered around the *"Mask Guardian"* identity, focusing on distinct silhouettes and expressive mask motifs.
* **Visual Consistency:** Established coherent proportions, color palettes, and visual details across character assets so they read clearly against game environments.
* **Developer-Ready Asset Handoff:** Exported and organized structured visual assets to integrate smoothly into the programmers' build pipeline under tight jam deadlines.
